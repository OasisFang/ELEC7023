# ELEC7023
Assignment for ELEC7023

## Overview
This Python script contains three tasks: a simple calculator, a question-answering bot, and a turtle graphics drawing. Each task demonstrates different programming concepts and functionalities.

---

## Tasks

### Task 1: Simple Calculator
The calculator allows the user to perform basic arithmetic operations:
1. The user inputs two numbers.
2. The user selects an operation (`+`, `-`, `*`, `/`).
3. The program calculates and displays the result.

### Task 2: Question Answering Bot
The bot responds to specific questions:
- If the user asks "hello", the bot replies with a greeting.
- If the user asks about "python", "jetson", "ai", or "name", the bot provides predefined answers.
- For any other input, the bot responds with "Sorry, I don't understand."

### Task 3: Turtle Drawing
This task uses the `turtle` module to create a colorful starburst pattern:
1. A turtle object is created and set to maximum speed.
2. The background is set to black.
3. A loop draws 100 lines, changing the color and direction to create a vibrant pattern.
